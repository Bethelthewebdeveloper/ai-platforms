Call the ZEN agent

POST http://localhost:5000/v1/agents/run with an X-API-Key header and a JSON body containing prompt.

const response = await fetch("http://localhost:5000/v1/agents/run", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-API-Key": process.env.NEXORA_API_KEY
  },
  body: JSON.stringify({ prompt: "Summarize this customer feedback" })
});

const result = await response.json();
console.log(result.output);

Store the key on your server. Replace the local URL with your deployed API URL when you go live. Token usage and quota errors are included in API responses.
